Featured · Thesis

Four Raspberry Pis. One supercomputer.

A hybrid MPICH cluster — one Raspberry Pi 5 leading three Pi 3B+ nodes.

Parallel jobs written in Python with mpi4py.

Benchmarks for matrix multiplication, image processing and stress testing.

Thesis deep dive

Inside the cluster.

Head node
Raspberry Pi 5 · 4× Cortex-A76 @ 2.4 GHz
Workers
3× Raspberry Pi 3B+ · 4× Cortex-A53 @ 1.4 GHz, 1 GB RAM each
Total cores
16
Software
MPICH · Python · mpi4py
Benchmarks
Matrix multiplication · Image processing · Stress tests
  1. 1

    Split the job

    The head node divides the work, for example the rows of a large matrix or strips of an image.

  2. 2

    Send it out

    MPI sends each piece to a node over the network. Every node, the head included, gets its own rank.

  3. 3

    Compute in parallel

    All four boards work on their piece at the same time.

  4. 4

    Bring it back

    The results are gathered on the head node and combined into the final answer.

Mixing one Pi 5 with three Pi 3B+ boards makes this a hybrid cluster: the head node's cores are much faster than the workers'. The benchmark suite runs real workloads across that uneven hardware.

What I built
